# ختمة السنة — النسخة التجريبية الأولى

## ما الذي يعمل الآن؟
- واجهة عربية RTL.
- إنشاء خطة لصحيح البخاري عبر إدخال إجمالي الأحاديث المعتمد في نسختك.
- تحديد الورد اليومي وحساب المدة التقريبية.
- حفظ التقدم محليًا على الجهاز.
- عرض نطاق الورد.
- استيراد ملف JSON للأحاديث وعرض نصوصه.

## ما الذي لم يُنفذ بعد؟
- تنبيه يومي موثوق في الخلفية.
- مزامنة الحساب بين الأجهزة.
- قاعدة أحاديث معتمدة ومدققة.
- دعم بقية كتب السنة.
- نشر المتاجر.

## تشغيل المشروع من الهاتف
1. فك ضغط الملف باستخدام مدير الملفات.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد.
3. من إعدادات المستودع فعّل GitHub Pages من فرع `main` ومجلد `/root`.
4. افتح رابط الموقع الناتج في Chrome أو Safari.
5. من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

ملاحظة: خصائص PWA والتخزين المؤقت تحتاج إلى HTTPS؛ فتح `index.html` مباشرة من مدير الملفات لا يفعّل كل الخصائص.

## صيغة ملف الأحاديث
استورد JSON على هيئة مصفوفة. كل عنصر يحتاج رقمًا ونصًا:

```json
[
  {
    "number": 1,
    "text": "نص الحديث بعد التحقق من المصدر والطبعة",
    "book": "كتاب بدء الوحي"
  },
  {
    "number": 2,
    "text": "نص الحديث التالي بعد التحقق",
    "book": "كتاب بدء الوحي"
  }
]
```

الاستيراد في هذه النسخة مؤقت داخل جلسة الصفحة؛ لا يغني عن تجهيز قاعدة بيانات موثوقة مدمجة أو قابلة للتنزيل في الإصدار التالي.

## تنبيه علمي وحقوقي
لا تُدخل نصوصًا أو أرقامًا قبل تحديد مصدر رقمي موثوق، والطبعة/الترقيم، ومراجعة النصوص، والتحقق من حق إعادة التوزيع. قد تختلف أرقام الأحاديث وعددها بحسب طرق العد والترقيم.

## ملاحظة تقنية
إشعارات الويب الدورية لا تعمل بصورة مضمونة في الخلفية على جميع الهواتف والمتصفحات. لذلك لا نعد المستخدم بمنبه يومي موثوق في هذه النسخة. عند الانتقال لتطبيق أصلي باستخدام Flutter أو حل مناسب، نضيف جدولة التنبيهات واختبارها على Android وiOS.
